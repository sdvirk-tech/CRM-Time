# CRM-Time — фазы 1–2

Мини-CRM «швейцарский нож»: **канал → AI-процесс (модель на слоте) → действие**, плюс входящие, контакт и очередь лидов.

Приёмка: критерии в ТЗ MVP + решения владельца 9–13 (палитра, приём в AI-чате, полная карточка груза, отправка менеджером, промт в UI / пинг / маршрутизация / опрос Telegram). Холст линейный, чат/Telegram, явная модель vs дефолт = «срочно» человеку, Compose, `DEPLOY_MODE`.

## Compose с нуля

```bash
cp .env.example .env
# задайте APP_SECRET (длинная строка). Ключи JEV/QWEN/OPENAI — по желанию.
# Без ключей parse/draft идут через тестовый провайдер mock.

docker compose config          # файл валиден, если есть postgres и порт 3000
docker compose up --build      # web + PostgreSQL, если сборка образа проходит
```

Откройте http://localhost:3000 — регистрация владельца, онбординг, холст.

На overlayfs `docker compose build` / `up --build` часто падает с `invalid argument`. **Это не зелёная сборка и её нельзя подменить.** Поднимите только Postgres и приложение локально:

```bash
cp .env.example .env
# DATABASE_URL=postgresql://crm:crm@localhost:5432/crm
docker compose up db -d
npm install
npx prisma migrate deploy
npm run dev
```

Прогон приёмки по API: `npm run test:phase1` (фаза 1 + фаза 2; сервер должен слушать `:3000`). Отдельно фаза 2: `npm run test:phase2`.

| Переменная | Смысл |
|---|---|
| `DEPLOY_MODE=saas` | много воркспейсов, публичная регистрация |
| `DEPLOY_MODE=box` | публичная регистрация выключена после первого владельца, **один воркспейс** |
| `APP_URL` | публичный URL (сниппеты, ссылки). Если задан `PUBLIC_URL` — берём его |
| `PUBLIC_URL` | HTTPS-адрес для Telegram webhook; кнопка «Перерегистрировать webhook» на слоте |
| `APP_SECRET` | JWT и шифрование токенов бота |
| `DATABASE_URL` | в Compose для `web` задаётся на `db`; локально — `localhost:5432` |
| `JEV_API_KEY` / `QWEN_API_KEY` / `OPENAI_API_KEY` | слот модели доступен; нет ключа — серый, приложение живо |

## Как собрать цепочку

1. Палитра слева: **Чат на сайте** или **Telegram** → **Разобрать входящее** → **Черновик ответа** → **Создать лид**. Форма сайта — короткий контакт (имя, телефон, «написать в чат»), не анкета ТН ВЭД.
2. На AI-слоте выберите **явную** модель (или оставьте пусто — сразу **срочно** свободному менеджеру/владельцу; форма всё равно создаст лид, чат — когда карточка полная).
3. Sheet канала: сниппет (цвета `#F2F2F2` / `#99CCFF` / `#C5E2FF`, Calibri), тестовая заявка, для Telegram — токен и тест `getMe`. `/start` сбрасывает сессию и шлёт приветствие; «хочу менеджера» — срочно человеку. Кнопка «Перерегистрировать webhook» берёт `PUBLIC_URL`. Нет HTTPS — слот включает **опрос getUpdates** (живой бот без webhook).
4. Входящие и очередь лидов — рабочий стол. **Приём заявки — диалог** (виджет `/c/{key}` и Telegram) с промптом МАКС и базой ВЭД. Промт МАКС правится на вкладке «Процесс → модель» (воркспейс, не Git). Бот спрашивает пустые поля; ссылка и фото идут в описание. После «Итоговые данные» — лид **Новый** с полной карточкой во входящих. Коммерческий черновик уходит в чат/Telegram только по **Отправить**. Явная модель отвечает, пока собирает карточку; пустой слот / дефолт — срочно человеку, без автоотправки. Молчит клиент после ответа менеджера — «завис» + черновик **пинга**; в чат пинг уходит по кнопке, автоотправка только если на слоте «Пинг клиента» выбрана явная модель. Несколько менеджеров: свободный пул или по кругу; «взять» как раньше. Статьи в **Знания** (папка ВЭД) подмешиваются в промпт (не RAG). Журнал `/log` + CSV. 5 неверных паролей → 15 минут паузы.

`deep_analysis` в палитре серый без ключа в env — на цепочку не влияет.

`DEPLOY_MODE=box`: первый владелец регистрируется и проходит онбординг; дальше публичная регистрация закрыта, второй воркспейс не создаётся. Менеджера зовут приглашением.
