# CRM-Time — фаза 1

Мини-CRM «швейцарский нож»: **канал → AI-процесс (модель на слоте) → действие**, плюс входящие, контакт и очередь лидов.

Приёмка: критерии в ТЗ MVP + решение владельца 2026-09-24 (приём в AI-чате, карточка груза, не публичная форма ТН ВЭД). Холст, чат/Telegram, явная модель vs дефолт = «срочно» человеку, Compose, `DEPLOY_MODE`.

## Compose с нуля

```bash
cp .env.example .env
# задайте APP_SECRET (длинная строка). Ключи JEV/QWEN/OPENAI — по желанию.
# Без ключей parse/draft идут через тестовый провайдер mock.

docker compose up --build
```

Откройте http://localhost:3000 — регистрация владельца, онбординг, холст.

`docker compose config` проверяет файл. `docker compose build` на overlayfs может упасть с `invalid argument` — тогда локально: Postgres + `npm run dev`.

| Переменная | Смысл |
|---|---|
| `DEPLOY_MODE=saas` | много воркспейсов, публичная регистрация |
| `DEPLOY_MODE=box` | публичная регистрация выключена после первого владельца, один воркспейс |
| `APP_URL` | публичный URL (сниппеты, ссылки). Если задан `PUBLIC_URL` — берём его |
| `PUBLIC_URL` | HTTPS-адрес для Telegram webhook; кнопка «Перерегистрировать webhook» на слоте |
| `APP_SECRET` | JWT и шифрование токенов бота |
| `DATABASE_URL` | в Compose задаётся на `db` автоматически |
| `JEV_API_KEY` / `QWEN_API_KEY` / `OPENAI_API_KEY` | слот модели доступен; нет ключа — серый, приложение живо |

Локально без Docker-образа приложения (Postgres уже в Compose или системный):

```bash
cp .env.example .env
# DATABASE_URL=postgresql://crm:crm@localhost:5432/crm
npm install
npx prisma migrate deploy
npm run dev
```

Прогон приёмки по API: `npm run test:phase1` (сервер должен слушать `:3000`).

## Как собрать цепочку

1. Палитра слева: **Чат на сайте** или **Telegram** → **Разобрать входящее** → **Черновик ответа** → **Создать лид**. Форма сайта — короткий контакт, не анкета ТН ВЭД.
2. На AI-слоте выберите **явную** модель (или оставьте пусто — заявка всё равно создаст лид, но сразу **срочно** свободному менеджеру/владельцу).
3. Sheet канала: сниппет (цвета `#F2F2F2` / `#99CCFF`), тестовая заявка, для Telegram — токен и тест `getMe`. `/start` сбрасывает сессию и шлёт приветствие; «хочу менеджера» — срочно человеку.
4. Входящие и очередь лидов — рабочий стол. **Приём заявки — диалог** (виджет `/c/{key}` и Telegram) с промптом МАКС и базой ВЭД; после ответов AI пишет карточку груза (имя, телефон, телеграм, Max, описание, вес, объём, отправка, прибытие, маршрут АВИА/МОРЕ/ЖД/АВТО/СБОРКА, срок). Короткая форма сайта — только имя/телефон и «Написать в чат». Явная модель отвечает в Telegram и в чате; пустой слот / дефолт — срочно человеку, без автоотправки. Статьи в **Знания** (папка ВЭД) подмешиваются в промпт (не RAG).

`deep_analysis` в палитре серый без ключа в env — на цепочку не влияет.
